# Trident website — SEO keyword → URL ownership map

Internal reference (not public content) for the commercial-search pass. One
canonical page owns each search territory; supporting Intelligence/Insights
strengthen it through internal links and topical context. No page competes with
another for the same primary query (cannibalisation avoided).

Principle: relevance is earned through genuinely comprehensive, well-structured
content in Trident's institutional voice — not keyword insertion. British
"adviser" is primary; the "advisor" search variant is used naturally where it
reads well.
